Guide affilié

Faites souscrire des restaurants via votre lien personnel, présentez le produit avec le compte démo, puis suivez vos inscriptions.

2 Règle absolue : le lien Obligatoire

Le restaurant doit s’inscrire avec VOTRE lien personnel.

Sans inscription via ce lien :

  • le restaurant n’est pas rattaché à vous ;
  • aucune commission ne peut vous être versée.
« Pour souscrire, tu dois passer par mon lien. Sinon je ne peux pas être commissionné, et on ne pourra pas te suivre correctement. »
  1. Envoyez uniquement votre lien Restau Wheel.
  2. Faites ouvrir le lien devant vous si possible.
  3. Vérifiez que l’URL contient votre code (?ref=…).
  4. Évitez l’accueil général, un autre affilié, ou un vieux favori.

Pas de lien = pas de commission. Aucune exception « on régularisera après ».

4 Bonnes pratiques

Partager votre lien

  • Bouche-à-oreille local, commerçants, réseaux du coin.
  • QR code de votre lien sur place.
  • Message court + lien (WhatsApp, LinkedIn, Instagram).
  • Renvoyer le lien juste après la démo.
« Voici mon lien Restau Wheel pour créer ton compte resto. Passe uniquement par ce lien : [VOTRE LIEN] »

À éviter

  • Spam (emails / SMS / messages en masse).
  • Faux comptes ou inscriptions pour « tester » la commission.
  • Partager le mot de passe démo hors présentation.
  • Promettre des tarifs non validés.
  • Inscrire le resto sans son accord.

Suivre vos parrainages

  1. Gardez votre lien et votre code.
  2. Notez qui vous avez prospecté et quand.
  3. Les inscriptions via votre lien apparaissent sur votre profil affilié.
  4. Si le resto « s’est inscrit » mais n’apparaît pas : vérifier le lien utilisé.

Litige commission

Contactez le support avec : nom / code affilié, nom + email du resto, date approx., preuve du lien partagé.

Confidentialité

  • Ne stockez pas les mots de passe des restaurants.
  • Ne diffusez pas emails / téléphones / stats hors besoin.
  • Compte démo partagé : aucune donnée personnelle dessus.
  • Prospectez loyalement (RGPD).
